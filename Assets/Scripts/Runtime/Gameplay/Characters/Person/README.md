# People Spawn System

Система спавна и управления людьми на карте с использованием MVP паттерна и DetectionService.

## Архитектура

### MVP Структура
- **PersonModel** - Модель данных человека с поддержкой `IDetectable`
- **PersonView** - Unity компонент для отображения и анимации
- **PersonPresenter** - Бизнес-логика и связывание Model с View

### Основные компоненты

#### PersonModel
- Реализует `IDetectable` для интеграции с DetectionService
- Управляет состояниями: Idle, Fleeing, Consumed
- Обрабатывает движение и позиционирование
- Автоматически регистрируется/разрегистрируется в DetectionService

#### PersonPresenter  
- Обрабатывает обнаружение игрока через DetectionService
- Управляет логикой убегания от игрока
- Обрабатывает столкновения с игроком (поедание)
- Параметры обнаружения:
  - Расстояние обнаружения: 8 единиц
  - Угол обзора: 360° (круговой)
  - Интервал проверки: 200мс

#### PersonView
- Unity MonoBehaviour с поддержкой анимации
- Управляет визуальными эффектами (частицы, звук)
- Обрабатывает столкновения через OnTriggerEnter
- Поддерживает состояния анимации для разных состояний PersonState

## PeopleSpawnService

### Функциональность
1. **Поддержание целевого количества** людей на карте
2. **Спавн за камерой** - приоритетный метод размещения
3. **Очередь ожидания** - когда нет места за камерой
4. **Объектный пул** - переиспользование объектов для производительности
5. **Автоматическая очистка** потребленных людей

### Параметры спавна
- Радиус спавна: 50 единиц
- Минимальное расстояние от игрока: 15 единиц  
- Максимальное расстояние от игрока: 40 единиц
- Расстояние спавна за камерой: 20 единиц
- Интервал проверки спавна: 1 секунда

### API
```csharp
// Инициализация с целевым количеством людей
peopleSpawnService.Initialize(20);

// Изменение целевого количества
peopleSpawnService.SetTargetPeopleCount(30);

// Получение текущего количества активных людей  
int activeCount = peopleSpawnService.GetActivePeopleCount();

// Ручной спавн одного человека
peopleSpawnService.SpawnPerson();

// Удаление человека из отслеживания (при поедании)
peopleSpawnService.RemovePerson(personTransform);
```

## Поведение людей

### Состояния
- **Idle** - Спокойное состояние, стоят на месте
- **Fleeing** - Убегают от игрока к случайной точке
- **Consumed** - Съедены игроком, отключены

### Логика обнаружения игрока
1. Каждые 200мс проверяют наличие объектов в радиусе 8 единиц
2. При обнаружении игрока вычисляют направление убегания
3. Выбирают случайную точку на расстоянии 10-20 единиц в противоположном направлении
4. Начинают движение к точке убегания
5. По достижении точки возвращаются в состояние Idle

### Логика поедания
1. При столкновении с игроком (OnTriggerEnter) проверяется тег "Player"
2. Если возможно поедание (CanBeConsumed), вызывается ConsumeByPlayer()
3. Запускается анимация поедания и эффекты
4. Объект отключается и возвращается в пул через 100мс

## Интеграция

### GameplayCompositionRoot
Система интегрирована в `GameplayCompositionRoot`:
1. DetectionService создается с размером ячейки 10 единиц
2. PeopleSpawnService инициализируется при старте геймплея  
3. Целевое количество людей по умолчанию: 20
4. При остановке геймплея количество устанавливается в 0

### Зависимости
- `com.azzazello.detectionservice` - для обнаружения объектов
- `com.azzazello.mvp` - MVP паттерн
- `com.azzazello.disposable` - управление ресурсами
- `ITickHandler` - система обновлений
- `IResourceLoader` - загрузка ресурсов
- `ICameraService` - работа с камерой
- `IInGameLogger` - логирование

## Производительность

### Оптимизации
- **Spatial partitioning** через DetectionService (grid-based)
- **Object pooling** для переиспользования объектов
- **Интервальные проверки** вместо каждого кадра
- **Батчинг операций** (максимум 3 спавна за кадр)
- **Автоматическая очистка** неактивных объектов

### Рекомендации
- Размер ячейки DetectionService должен соответствовать радиусу обнаружения
- Количество людей следует ограничивать в зависимости от платформы
- При большом количестве людей можно увеличить интервалы проверок
